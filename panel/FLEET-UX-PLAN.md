# 多机总控交互改造实施方案

用户确认：采用常见管理控制台交互，总览优先、复杂编辑宽侧栏、简单操作弹窗；本轮实现当前状态、用量和会话内短时速率趋势。

## 范围与约束

- 面向约 50 台 VPS、每台约 10 条代理，保留各 VPS 独立面板和数据库。
- 复用现有 UI、代理表单和受限远程转发接口，不引入依赖，不改变授权和升级执行机制。
- 保留已有自动获取最新正式版本、面板与 Agent 实际版本展示改动。
- 不发布版本、不操作生产服务；不新增长期指标存储、计费系统、WebSocket 或外部代理的虚构速率。

## 实施顺序

1. **信息架构**：总览、VPS、代理、外部代理、维护任务、设置独立入口。接入授权与监控策略进入设置，首页不再平铺全部对象。
2. **列表与选择**：默认每页 20 条，名称搜索、VPS/状态筛选；选择本页、选择全部筛选结果、清空选择；跨页选择保留且明确显示总数与所属 VPS，确认弹窗列出实际操作范围。无目标时禁止执行，不静默跳过失联对象。
3. **总览**：VPS 联系状态、Agent 状态、代理异常、版本不一致；区分网卡速率与代理业务速率、各代理当前周期用量。显示采样时间、有效数据覆盖率，缺失/过期显示未知，不能当零。沿用约 30 秒远端同步、5 秒读取缓存，明确非秒级实时。
4. **短时趋势**：仅保留当前页面会话内最近 10 分钟、最多 120 个采样点；重复快照不伪造成新样本，未知点留空，覆盖范围变化显式标注。刷新页面不保留历史。
5. **原位编辑**：打开具体代理的宽侧栏；外部代理弹窗；先读目标 VPS 最新状态，所有保存、检测、预览、应用请求显式绑定目标 VPS。保存后保留列表筛选、分页和选择；应用影响其他代理时确认，明确已保存但未应用的状态。保留明确的免密进入远端面板入口。
6. **维护反馈**：选中 VPS 后升级/重启，确认目标、数量和影响；提交即展示任务详情，逐台状态、失败原因、暂停恢复；任务列表分页，运行中提示可重新打开详情。
7. **验证与收尾**：非特权独占目录运行 TypeScript、构建与模拟浏览器测试。覆盖 50 VPS/500 代理分页、跨页/隐藏选择、同 ID 不同 VPS 的路由隔离、编辑失败保留输入、过期指标、任务进度以及现有监控功能。检查小屏布局。清理浏览器进程及构建产物，不更改生产权限。

## 验收流程

- 总览发现异常 → 筛选 VPS → 查看状态与所属代理 → 原位编辑 → 保存并观察应用状态，全程不离开总控。
- 搜索跨 VPS 代理 → 跨页选择 → 确认“代理数 / VPS 数”和具体对象 → 提交 → 查看逐台任务结果。
- 选择 VPS → 获取最新正式版 → 确认版本与中断影响 → 升级 → 观察逐台进度；失败后核对原任务再继续。
- 旧快照、离线 Agent、无采样和无外部代理统计均明确标记，不能表现为健康或零流量。

## 本轮限制

- 浏览器接口为模拟数据，未验证 50 台真实 VPS 的网络延迟、负载、升级执行或通知送达；未承诺秒级实时。
- 目前由前端分页，后端仍返回全部授权 VPS 快照；50 台规模只做了交互模拟，不代表后端容量测试。
- Vite 构建通过，但主脚本约 520 KB（gzip 约 164 KB）触发体积提示。本轮没有追加全站代码拆包。
- 尚未 Git 提交、发布版本或部署；页面刷新会清空短时趋势，跨页面退出总控后列表状态不持久化。


## 第二轮模拟客户评审与修复

本轮按个人玩家、商业运维、新手及交互设计四种角色复评。它们是代码支持的角色模拟，不是真实客户访谈；评审停止标准为本轮核心查看、编辑、批量维护路径无明确阻碍，不追求无限扩展功能。

已修复：

- 同步失败/待生效优先于配置停用；后端同步状态比较编辑配置与已应用配置，避免未下发修改显示已同步。
- 远端按钮改为“保存并预览”，关闭预览后本会话提供“继续应用”；外部代理弹窗保护未保存输入。
- 总控独立时钟使持续相同断网错误下的旧采样也按时过期，成功连接清除对应网络错误。
- 暂停任务说明核对原结果不等于重新执行；提供选择失败及未执行对象入口，排除成功和结果未知对象，重新提交仍需确认范围。
- 首页异常按失联、Agent 故障、其他运行异常、版本不一致排序；各列表保留搜索、筛选、页码和排序，返回 VPS 不重新找位置。
- 增加异常优先/吞吐排序及现有探测详情；吞吐排序与速率展示使用相同有效性条件，明确低吞吐不代表性能差。
- 手机表格转卡片，名称和操作在前两行；选中 VPS 后才显示维护工具。接入设置明确本机授权与远端取码方向。
- 趋势图按真实十分钟时间定位，显示刻度、可点选数值与覆盖数量，保留明细表。

复评结论：四个角色均确认原有核心问题已处理。个人用户补充的“停用代理旧速率参与排序”已修正并获复核关闭。剩余非阻碍限制：密集图表点在手机上不易精确点击，可使用数值明细；继续应用提示是会话状态，刷新后从待应用状态或 VPS 详情继续处理。
