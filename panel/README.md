# Chain Panel

个人自用的多服务器 Web 管理台，支持多条 VLESS 代理链和 TCP/UDP 转发。节点、线路和连通检查在 Web 中管理。

## 安装控制台

在服务器上运行安装向导：

```bash
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo bash
```

选择「安装控制台与本机节点」，按提示选择访问方式和端口。默认一起安装控制台和本机 Agent，并自动把本机接入 Web；也可选择仅安装控制台。向导会准备程序、配置服务，最后显示访问地址和登录令牌。安装过后直接输入 `chainctl` 即可打开管理菜单。

已经有源码仓库或解压后的发行包时，运行 `sudo ./scripts/install-server.sh` 即可，向导会优先使用本地包。在线安装依赖维护者发布的 [正式安装包](https://github.com/dovetaill/vless-chain/releases)；尚无正式包时会明确提示，不要求使用者手动编译。

支持 Linux x86_64 / aarch64、systemd、Python 3.10+，发行包会检查 glibc 兼容性。缺少 Python 时脚本尝试通过 apt/dnf 安装；无需自行安装 Node.js、Rust 或 Xray。

## 添加服务器

1. 登录 Web，打开「服务器」，点击「添加服务器」。
2. 选择「在 Web 安装」，填写节点的 root SSH 密码或私钥，检测并核对服务器 SSH 指纹。
3. 点击「安装并接入 Agent」，控制台会传送程序并完成安装。也可选择「使用脚本安装」，在节点运行安装脚本并粘贴接入码。
4. Web 显示「节点已在线」后，就可以创建线路。

接入码包含节点凭据，请私下保存；遗失后在服务器卡片中选择「重置接入码」。默认安装已自动接入本机节点，不需要再手动添加一次。Web 远程安装支持 root SSH 密码或无口令私钥；SSH 凭据只用于本次操作，安装后清除。

## Agent 是什么

控制台负责 Web 页面和线路管理；Agent 在每台参与转发的服务器上运行，接收配置、管理 Xray 并上报状态。没有受管 Agent 时，控制台能打开，但不能建立实际代理线路。默认一起安装后，本机就能作为入口或出口；其他转发服务器各接入一个 Agent。

## 日常管理

只需记住一个入口：

```bash
chainctl
```

菜单提供安装、重新接入、自动升级、状态、日志、启动、停止、重启、备份、回滚和登录信息。只安装一种组件时自动选中；两种都安装时按编号选择。需要管理员权限时会调用 sudo。

想了解命令行用法时输入 `chainctl help`，无需记忆参数。选择「更新到最新版本」后会自动下载正式包，保留配置和数据；升级、备份或重启可能使相关连接短暂重连。回滚恢复程序版本，保留当前业务数据。

## 在 Web 使用线路

在「代理线路」或「端口转发」中依次选择入口、中转和出口，可同时保存多条不同路径。先保存草稿，再点击「预览并发布」，确认影响范围后应用，最后执行连通检查。每条代理线路有独立分享链接；只修改中转或出口时保留已有入口信息。
