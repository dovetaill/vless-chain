# v0.2.49

- REALITY 生成配置增加前置 SNI 检查；诊断分别展示握手、数据交换、错误或缺失 SNI 的拦截结果，以及 CDN 风险提示。CDN 提示不是安全保证；已有保留的自定义配置不会自动重写。
- Agent 内核日志支持关闭、清空、大小上限及按小时或天保留。默认保留 1 小时、最多 50 MiB；历史分段按 UTC 日期压缩并定期清理，当前写入文件保持未压缩。这些限制不涵盖系统 journal 或自定义程序直接写入的日志。
- 新升级器取消自动备份，成功升级后清理可确认安全删除的历史发行目录，保留当前使用及无法确认的目录。首次从旧升级器升级时仍执行旧逻辑，需要再运行一次更新才能使用新清理逻辑；已有备份归档不自动删除。
- 修复旧安装缺少 chain_time 时升级被直接中断的问题，文档补充在线引导修复命令。
- 修复新建空节点尚未配置线路时误报“代理内核未运行”；有配置、未同步或存在错误时继续提示。
- 提交原生 Rust 管理器迁移基础及隔离升级测试。本版发行包尚未接入 Rust chainctl，不会卸载 Python 管理脚本；系统服务与 Web 升级的原生切换尚未完成。

验证：已完成 REALITY 定向测试及隔离真实握手与数据交换检查、日志和发行目录清理测试；最新非特权模拟环境通过 16 项 Rust 原生管理器测试、4 项实际 CLI 离线升级测试、3 项时间诊断及缺失模块回归测试、前端节点状态断言和 TypeScript 检查。离线升级使用模拟服务，不代表真实 systemd 或 Web 原生切换已验证。三平台发行构建和安装检查以发布 Actions 结果为准。

## 升级与自测

1. 等待本版本正式 Release 发布后，在旧安装上执行以下完整命令；纯 Agent 节点追加 `--component agent`：

   ```sh
   curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --non-interactive
   ```

2. 网页确认面板和 Agent 为 0.2.49。刷新总控；空节点应不再出现内核未运行误报。有线路的节点仍应应用成功、内核运行，并能通过原客户端访问。
3. 再执行 `sudo chainctl update --non-interactive`，确认不再出现缺少 chain_time 的错误。查看 `/opt/chain/releases`：已确认不在使用的历史发行目录应被清理；检查原有线路、登录和订阅仍可用。
4. 日志页面设置 1 小时、较小的容量上限并保存，刷新确认值保留。产生正常连接日志后检查容量和清理；跨 UTC 日期或达到分段大小后应有压缩历史文件。关闭日志后确认受控文件日志停止增长，重新开启后恢复。
5. 保存并应用 REALITY 线路，执行“验证 REALITY 握手”，分别检查数据交换、SNI 拦截和 CDN 提示；用原客户端实际连接。CDN 提示为未知或无提示，不代表绝无回落风险。

本版不能用来验证“已完全去掉 Python”；该迁移仍在进行。
