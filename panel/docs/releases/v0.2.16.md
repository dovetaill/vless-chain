# v0.2.16

- 停止构建和发布 macOS Intel 包。正式发行保留 Linux x86_64、Linux ARM64 和 macOS 14+ Apple Silicon；三个平台全部验证通过后发布。
- 包含 v0.2.15 的安装修复：curl 管道安装补齐 `chain_ingress.py`；安装及中断后重试复用未过期证书，不执行 Certbot 申请。证书不存在或已过期才申请，已有文件损坏或私钥、域名不匹配时停止报错。
- 安装重试即使临近到期也复用证书；日常定时自动续期继续按 Certbot 正常策略执行。

已有安装升级：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --component panel --non-interactive
```

此前证书申请成功后中断的安装，显式重新配置原域名：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- install --domain 你的面板域名 --local-host 服务器公网IPv4
```

无需删除已有证书或卸载。升级保留配置、业务数据和凭据，重启控制台及匹配的本机 Agent。

发布检查覆盖三个平台的附件聚合与校验；证书复用、过期、损坏及中断重试回归测试继续执行。原生构建及安装冒烟测试由标签工作流验证。
