# v0.2.54

- 增加自用、小型运营、商业运营三种工作模式，调整导航与引导；切换模式不改变账务、权益或权限。修复新建代理后重复保存、未保存内容误关闭和手机端导航问题，补齐订阅及二维码交付入口。
- 增加待收款订单、人工确认收款、取消订单、人工退款与金额纠错。重复确认保持幂等，响应丢失后先查询原操作；原收款及历史租期保留。对账支持客户、北京时间日期筛选与 CSV 导出。尚未接入在线支付。
- 增加客户共享套餐、成员额度与分范围私密查询链接，同一面板下多个 Agent 共用客户预算；独立线路出租继续保留。只有未出租、未发布的新草稿可绑定套餐，不自动合并旧客户权益或修改原连接凭据。
- 增加运维、财务、只读成员及独立登录密钥、撤销与操作者留痕。后端按角色校验并返回脱敏状态；远端转发、免密跳转和复杂配置修改仍限管理员。
- 修复客户额度申请保存失败后的账本、告警回滚；客户授权强制要求新版计费协议，避免旧 Agent 恢复套餐配置后按错误倍率扣量。供应资源仍按实际字节独立记账。
- 增加 SQLite 旧程序写入保护：新版文档保存后，旧版本缺失订单、套餐、成员等新增字段的覆盖写入会被拒绝，防止升级失败恢复旧程序时静默丢数据。原库打开时不重写历史业务记录。
- 改善监控轮询公平性、倍率额度告警、空 Agent 维护验证与角色入口提示。发行检查现覆盖完整面板单元测试及真实共享套餐流程，包含新账务、权限与重启保护。

## 升级与边界

升级前备份面板数据库、Agent 流量与资源账本、令牌及配置。先升级面板及 Agent，等待 Agent 上报 `customer_plan_version=1`，再为新草稿启用套餐。普通独立线路沿用原权益、凭据和账本。

新版已经接收订单或流量后，不要用旧数据库覆盖当前库。旧面板因写入保护报错时，应恢复兼容的新版程序，不删除保护触发器；共享额度续领仍受授权有效期约束，不能依靠旧版本长期维持服务。

套餐额度在流量准入时预扣，转发取消或本地落账失败也可能占用该块额度；不宣称精确送达字节计费。控制端失联后仅可使用短期有效授权，当前缓存许可约 9 秒。套餐只跨同一面板的 Agent；多个独立面板暂不共享客户账本。成员个人 TOTP / Passkey 尚未提供，原管理员验证方式保持不变。

20 台 VPS、1000 客户、3000 线路属于规模目标，未经过本次容量压测，不作为商业容量承诺。
