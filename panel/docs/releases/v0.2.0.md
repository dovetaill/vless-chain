# Chain Panel v0.2.0

本版将代理接入、普通端口转发和网站反代分开，补齐总览、流量控制、客户端导出与登录安全。日常操作默认保存并应用；共享服务器上的变更会提示受影响的线路。

## 主要更新

- 新增控制台总览、可收起侧栏、手机布局和登录页面；目标地址与端口独立填写，REALITY 目标端口默认 443。
- 代理入口支持 VLESS/REALITY、HTTP、SOCKS5、Shadowsocks 2022 和 Trojan/TLS。普通 TCP/UDP 转发无需填写代理协议参数，多跳路径由平台生成内部配置。
- 支持已有代理作为出口、购买的中转入口；服务器默认使用脚本与接入码接入，SSH 自动安装保留为可选方式。
- 接入窗口提供本地生成的二维码、分享链接、完整 Mihomo / Clash Meta YAML、节点 YAML 和可撤销订阅。
- 新增按域名的网站反代、手工 TLS 证书、WebSocket，以及基于 Certbot 的自动申请和续期。
- 新增线路流量统计、近七天总览、月额度和告警；上传、下载分别按 Mbps 限速，同一线路所有连接共享预算，TCP 与 UDP 不会各自重复获得额度。
- 新增管理员密钥轮换、TOTP、一次性恢复码、Passkey 注册与登录，以及本机 `chainctl reset-auth` 安全恢复入口。
- 提供含 13 张真实界面截图的[图文手册](https://github.com/dovetaill/vless-chain/blob/v0.2.0/panel/README.md)。

## 安装与升级

新安装：

```bash
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/v0.2.0/scripts/install-server.sh | sudo bash
```

在线安装和更新会下载最新正式 Release。支持 Ubuntu 22.04+ / Debian 12+、Linux x86_64 / aarch64、systemd、glibc ≥ 2.35、Python ≥ 3.10；发行包包含 Xray 26.3.27，无需在服务器安装 Node.js 或 Rust。构建增加 OpenSSL 开发依赖，运行环境需提供系统 OpenSSL 3 库。

**从 v0.1.x 升级时，先更新所有 Agent，再更新控制台。** 本版入口使用 Agent 网关能力，新控制台会拒绝向不具备该能力的旧 Agent 应用入口配置。

1. 在每台已接入服务器执行 `sudo chainctl update --component agent`。
2. 确认 Agent 恢复在线，再在控制台所在服务器执行 `sudo chainctl update --component panel`。
3. 刷新浏览器，检查服务器在线状态与现有线路。更新会重启对应组件，请安排可接受的短暂中断窗口。

控制台和本机 Agent 同机安装时，也按上述顺序分别更新。安装器保留原有身份与业务配置；建议升级前备份现有数据。Passkey 需要稳定的 HTTPS 域名，或用于本地测试的 localhost。

下载对应架构的 `tar.gz` 和 `SHA256SUMS` 可离线安装，包内含图文手册与安装脚本。

## 验证与边界

本版已完成 Rust 单元检查、前端构建、安装与网络脚本测试，以及真实 Xray、Mihomo 和浏览器集成验证，覆盖五种代理、TCP/UDP 转发、HTTPS/WebSocket、并发聚合限速、额度持久化、订阅撤销、TOTP 与虚拟认证器 Passkey 流程。需要隔离 SSHd 的测试和当前环境禁用的 IPv6 测试未执行。

- 公网 ACME 证书签发未做真实域名端到端验证；需要 DNS 正确解析且 Agent 可使用公网 TCP 80，不会接管已有 Nginx。
- 线路更换入口服务器时，不会跨服务器合并历史流量和月额度。统计约每 2 秒落盘，异常断电可能丢失最后一小段统计。
- 当前受管入口使用 IPv4 监听；协议支持范围及传输组合见图文手册，并非所有客户端或代理扩展都受支持。
- 网站流量按请求/响应体与 WebSocket 数据计量，不能当作运营商账单。

原有 SSH 脚本与控制台独立运行；原始 Metronic 主题压缩包不进入源码提交或发行包。
