# v0.2.75

- 修复节点尚未上报系统采样时，控制台读取空值导致白屏的问题；本机仪表盘、总控图表和 VPS 详情均接受空采样，继续显示其他节点的数据。
- VLESS 创建界面明确区分“创建一个代理”和“批量创建不同方案”。单独创建可以直接选择 REALITY + Vision、TLS + Vision、REALITY + XHTTP 或 TLS + XHTTP，显示方案说明及将创建的数量，无需进入批量模式选择 TLS。
- 保留默认 REALITY + Vision，并明确展示当前选择；TLS 地址不符合域名要求时提示修正，不再因地址是 IP 而静默切换为 REALITY。批量创建提前检查空选择、重复 REALITY 443 端口及统一入口的 SNI 冲突。
- 新建代理默认填写对应控制台的域名，总控内使用目标 VPS 的控制台域名；粘贴 HTTP/HTTPS 地址时自动提取主机名，去掉协议、端口、路径和查询参数。编辑已有代理保留原连接地址。
- 总控允许移除已离线或废弃的 VPS：先尝试撤销远端授权，再移除本地接入记录；远端不可达或未明确确认时，如实提示撤销尚未确认。本地保存失败仍返回错误，不宣告移除成功。
- “解除接入”改为带红色描边的“从总控移除”，确认提示说明操作范围。移除不会卸载或停止远端代理；远端授权及已有免密会话未确认撤销时，仍在使用的远端应在其面板解除总控绑定。

已完成空采样白屏、单独创建 TLS、地址处理、批量校验和总控移除的浏览器回归，以及远端撤销失败、本地保存失败和既有授权撤销的定向测试。浏览器测试使用模拟 API；不代表已验证真实 DNS、证书签发或客户代理整链传输。
