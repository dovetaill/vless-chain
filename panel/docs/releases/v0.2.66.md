# v0.2.66

- 将构建、内核准备、版本管理、发布和集成验收从 Python 迁移到 Rust `xtask`，同步普通 CI 与发行工作流。
- 将旧配置解析和迁移收进 Rust `chainctl`；Shell 只保留安装引导和命令入口。
- 自动证书使用原生 Rust ACME，支持 HTTP-01 与 Cloudflare DNS-01，并更新证书读取、备份与 HTTPS 运维逻辑。
- 删除已替代的 Python 源码和测试。仍使用 Python 管理器的旧安装应通过新版 `scripts/install-server.sh update` 升级。

验证：Linux x86_64 非特权隔离环境中完成前端构建、224 项 Rust 测试、静态 musl 发行构建、真实 Xray/Mihomo 校验、SSH 安装回归及 REALITY 大证书握手。完整发行 smoke 通过，覆盖升级、旧配置迁移、真实流量、套餐与财务幂等、HTTPS 及完整静态资源传输；独占 Alpine 容器中的 OpenRC 全新安装和失败恢复均通过。

3 项需要专门 Xray/TLS 环境的 Rust 用例保留原有忽略标记；macOS ARM64 和 Linux ARM64 未在本地执行，需由对应平台 Actions 验收。测试不修改宿主机生产服务或权限。
