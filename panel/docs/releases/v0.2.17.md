# v0.2.17

- `chainctl` 菜单新增「16 卸载本机全部组件」，可选择保留数据或清除配置、数据库及备份；两种方式都移除程序、服务和管理命令。
- 保留数据时保存恢复记录，重装复用原配置、管理员数据、Agent 身份和受管理的 HTTPS 域名；清除数据时同时删除服务账户。
- 卸载前校验文件归属，先停止服务和统一入口，再删除本项目的 Nginx 配置。保留其他网站、系统 Nginx 和面板 HTTPS 证书；Nginx 检查失败时恢复站点文件。
- 面板证书的续期在重装恢复 HTTPS 后继续。使用统一 443 的代理在重装后需从菜单重新启用统一入口。

验证：79 项脚本检查通过，包含卸载与重装恢复、删除保护、Nginx 配置恢复及 systemd / OpenRC / launchd 服务文件测试；OpenRC 和 launchd 的系统命令使用模拟验证。
