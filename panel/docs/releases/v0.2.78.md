# v0.2.78

- 首次安装、命令行、设置页和多机总控升级共用一套存储逻辑。程序包在安装分区直接解包并校验，切换成功后自动清理已退出的旧版本。旧任务留下的无用内核历史也会清理。
- 同机 Panel 与 Agent 使用相同程序构建时，独立升级 Xray 或 Mihomo 后继续共用一个发行目录。升级内核时，候选目录复用未变的文件。原链接验收失败仍会记录失败原因并保留 Agent。
- 独立安装脚本按本次压缩包及执行器大小选择临时目录，取消固定 3 GiB 门槛。小硬盘仍须能容纳当前程序、正在准备的候选版本和下载包。旧版网页升级已报空间不足时，通过最新独立安装脚本执行一次 `update --non-interactive` 即可使用新版维护执行器。
