# v0.2.19

安装时发现已有代理或 80/443 被占用，现在提供迁移接管、备份停用、保留旧服务并为新平台随机或手动选择端口等选项。

- 识别 systemd、独立 Docker/Compose 及 x-ui/3x-ui 管理的代理，接管前备份配置与服务状态。
- 支持的 Xray 入站保留原端口、UUID、密码及 REALITY 参数；无法完整转换的配置仅导入名称与原因，可在面板补充配置。
- 按安装时的选择，导入完成后自动停用旧服务，不等待待配置项目；失败时恢复旧服务。旧面板的订阅、流量配额和到期规则不迁移。
- 兼容时复用 443；保留旧服务时为新平台换端口。80 不可用时可提供与面板域名匹配的证书和私钥，续期仍由原工具负责。

自动转换采用保守范围：依赖旧反向代理、复杂路由、多用户或暂不支持的传输/协议参数会列为待配置，不能保证原客户端立即恢复；选择接管时请查看迁移预览。旧配置备份保存在 `/var/backups/chain-legacy/`。

已安装用户运行 `sudo chainctl update --latest --non-interactive` 升级。首次安装继续使用 README 中的一键安装命令。
