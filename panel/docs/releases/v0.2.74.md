# v0.2.74

- 在线安装先检查临时目录可用空间，优先使用 `TMPDIR` 或 `/tmp`，不足或不可用时自动改用 `/var/tmp`。按发行包允许的最大体积保守预留 3 GiB；候选目录均不可用时在下载前提示。
- 新安装的下载与完整解压共用本次私有临时目录，正常结束、失败或收到终止信号后统一清理，不删除此前安装或其他程序留下的文件。
- 临时解压不再逐个文件强制同步落盘，保留压缩包摘要、文件清单、逐文件摘要及安全路径校验，正式安装和状态写入逻辑不变。
- 增加临时空间不足、目录回退、失败及中断清理测试，并补充包内文件篡改和截断压缩包的拒绝与清理覆盖。
- 在线面板安装必须明确填写域名并使用 HTTPS 443，不再回退到 IP 或随机 HTTPS 端口；保留数据后重装也不会默认复用旧域名。升级与 Agent 接入入口保持不变。
- Nginx 重载后最多等待 15 秒，必须实际读取到正确的 HTTP-01 验证内容才继续签证书；持续 404、内容错误或超时仍报出真实原因并恢复原站点。
- 重复安装时识别本程序生成且内容未改动的 ACME 兜底站点，避免将其误判为域名冲突；外来或被修改的站点仍执行冲突检查。
- 代理迁移先识别真实可执行文件，再检查代理归属，避免把没有可执行文件的内核线程及已退出进程误报为代理；实际代理检查失败仍保留原进程并报告。
- 时间检查先向 Chrony 核实同步状态及校正量，已同步时避免依赖可能超时的 timedatectl 查询；未确认同步时继续原有检查与同步处理。
- 交互卸载提供“只删除程序、保留数据”和“删除程序及全部数据”选项，并分别要求明确确认。
- GitHub 已停用 `macos-14` 构建机，导致 v0.2.73 无法完成三平台发布。CI 和发布流程改用 `macos-15`，程序的 macOS 最低部署目标仍为 14.0；保留已推送的 v0.2.73 标签。

在 Linux x86_64 VPS 的磁盘临时目录中，以非特权身份对同一份 v0.2.72 正式包进行修改前后交错测试：校验与完整解压耗时由 7.29 / 3.70 秒降至 1.11 / 1.61 秒，四次均通过全部 92 个文件校验。该结果只覆盖解压与校验阶段，不代表整套安装或升级耗时。
