# v0.2.7

增加按代理独立出售的出租管理、运营总览和客户查询页，并完善实际转发中的流量权益控制。

- 总览显示主机 CPU、内存、磁盘、网速、最近 30 天流量趋势，以及每条代理的用量、余量和到期情况。
- 支持客户档案、人民币月付/季付/年付报价、人工收款后的开通与续费记录，以及自用代理的无限期设置。
- 租赁额度按北京时间的购买日逐月重置，月末保持原始日期锚点；有效期内续费不清零，过期重开恢复额度并重建周期。到期或耗尽自动停用，权益恢复后自动恢复，管理员手动停用保持不变。
- 公开查询页无需登录，凭完整代理配置或私密链接查询匹配代理的用量、余量、到期和报价；支持整份 Mihomo 配置及联系运营方续费。持有配置的人可以查询对应代理，请私下交付。
- 加强代理搜索和状态筛选，支持批量启停、续费、额度/限速修改、导出及删除。运营修改立即同步相关代理，离线时显示待同步，保留其他未应用草稿。
- 仅计量成功鉴权后的业务载荷，共享上传/下载限速与硬额度。Agent 使用 SQLite WAL/FULL 账本，在允许转发前提交计量；内核异常退出由 systemd 恢复已应用配置。提高 Agent 文件描述符上限，避免多协议 UDP 会话触及旧默认限制。

本轮已完成 48 项 Rust 库测试、9 项租赁 API 测试、前端构建及真实 HTTPS 浏览器流程。正式服务的 13 种协议/传输组合完成 156 项检查，64 并发累计 832 次 TCP 传输通过，配置 2 Mbps 的聚合实测为 1.941–1.963 Mbps；11 种支持 UDP 的组合分批完成 33 项额度/上下行控制检查，HTTP/HTTPS 不支持 UDP。一次 Hysteria 2 冷启动预热探测超时，改为逐个建立会话后，实测阶段仍保持 16 并发，定向补测通过。

已验证面板、Agent 和两种内核异常退出后的恢复；Agent 强杀后已确认转发流量的账本回退为 0；32 次相同并发续费只产生一条交易记录。未测试物理断电、跨运营商路径、多日稳定性及所有有序多跳组合。上述速率为同机测试，不代表公网带宽。

升级：`sudo chainctl update --component panel --non-interactive`。安装器会备份并升级、重启本机面板与 Agent，连接会短暂中断；远程 Agent 需分别更新。升级保留数据与凭据，已有 `traffic.json` 在首次启动新账本时导入一次，之后以 `traffic.db` 为准。账本先于转发提交，若进程恰在提交后、发送前退出，已计入的载荷可能尚未到达目标；耐久性依赖存储正确执行同步写入。
