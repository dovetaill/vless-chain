# v0.2.18

包含 v0.2.17 的卸载菜单、数据保留与重装恢复功能。v0.2.17 的 macOS 发布检查因新增测试漏掉服务调用隔离而失败，未生成正式发行包；本版补齐测试中的 macOS 服务调用隔离，不修改卸载业务逻辑。

- 菜单 **16「卸载本机全部组件」** 支持保留数据或清除应用数据，两种方式均删除程序、服务与 chainctl，并保留系统 Nginx、其他网站及面板 HTTPS 证书。
- 保留数据后重装可复用配置、数据库、Agent 身份和受管理的 HTTPS 域名；原有统一 443 代理需要重新启用统一入口。

验证：本地复现并修复模拟 macOS 环境下的测试失败；正式 macOS ARM64 结果由发行 CI 验证。仍不构建 macOS Intel 发行包。
