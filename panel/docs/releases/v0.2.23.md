# v0.2.23

修复独立 HTTPS 入口与 fronting 测试继承系统 Nginx 临时目录的问题，避免配置检查影响其他站点的目录属主。

- 独立 HTTPS 入口明确核对工作用户及主组，将五类临时目录和锁文件隔离到 `/var/lib/chain-panel-https`；拒绝接管不属于安装器、指向其他位置或属主权限不匹配的既有目录。
- 安装失败时清理本次创建且已停用的临时目录；卸载仅清理具有安装器归属标记的目录。
- fronting 测试隔离五类临时目录及锁文件，拒绝以 root 用户或组执行。
- 回归测试直接验证安装器生成的 Nginx 路径，并检查失败回滚、外部目录保护和卸载清理。

本次不会修复或重置已有系统目录的权限。已安装用户运行 `sudo chainctl update --latest --non-interactive` 升级。
