# Chain Panel v0.2.1

本版改善服务器接入流程，明确控制台本机、远程服务器和已有代理的使用方式，并修复列表更多操作菜单被裁切的问题。

## 更新内容

- 新增「使用控制台本机」入口，选择已接入记录后直接创建代理，不重复创建节点；节点离线或未接入时明确提示。
- 「接入另一台服务器」明确脚本应在目标服务器 B 执行，SSH 远程安装是可选替代方式。
- 修复节点安装命令未指定组件的问题，直接进入 Agent 安装向导，避免全新 B 误装控制台。
- 明确支持先在 B 自行搭建 VLESS，再导入分享链接，无需 SSH 或 Agent；导入不会接管 B 的服务配置。
- 修复列表菜单被滚动容器裁切的问题。

## 升级

从 v0.2.0 升级，等待本版本正式 Release 的安装包发布完成后，在控制台服务器执行：

```bash
sudo chainctl update --component panel
```

升级会短暂重启控制台，完成后刷新浏览器。本版未修改 Agent 协议，从 v0.2.0 升级无需同步更新 Agent。从 v0.1.x 升级仍需先升级所有 Agent，再升级控制台，参见 v0.2.0 发布说明。

## 验证与限制

接入流程改动已通过 TypeScript 检查、前端生产构建及隔离浏览器测试，覆盖本机选择、离线和空列表提示、远程安装命令与 SSH 切换、已有 VLESS 导入。浏览器测试使用模拟 API，不代表真实远程 SSH 安装验证。

控制台仍以受限账户运行，尚不支持从网页补装缺失的本机 Agent；需要管理员通过现有 chainctl 安装菜单补装。本机身份由用户按名称和地址选择，不根据域名猜测。
