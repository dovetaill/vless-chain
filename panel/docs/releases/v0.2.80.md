# v0.2.80

- 控制台支持浅色、深色和跟随系统的主题。右上角个人菜单可切换导航视图，主要管理页面适配窄屏。
- 开通或续费时，回执列出实际收款线路，提示与当前选择完全无关或部分重叠的订单。关闭旧回执会保留后来发起的待确认请求。客户账务可核对订单、原收款和退款或纠错的流水号。
- 多机总控支持按完整入口域名或 IPv6 地址及端口搜索。代理列表按后端的优先顺序显示 TLS 域名。外部代理可按协议和落地地址核对，兼容带插件参数的旧版 Shadowsocks 链接。
- 监控告警标明所属节点或代理，独立展示分段诊断结论并折叠内核日志。时钟恢复后不再显示过期的校时建议。
- 表格中的说明浮层可在滚动区域外展开，点击说明时保留复选框状态。屏幕阅读器可识别总控详情中的 CPU、内存和磁盘读数。
