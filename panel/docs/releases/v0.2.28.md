# v0.2.28

修复 Alpine/OpenRC 安装时服务显示启动成功、程序却因日志文件提前占用数据目录而退出的问题。安装器在启动前写入服务专属的目录归属标记，并识别 v0.2.25–v0.2.27 失败安装留下的受信任日志目录；保留日志和数据，不接管其他目录。

安装回滚后的报错直接提供日志读取命令，不再依赖可能尚未安装的 `chainctl`。

修复迁移 443 代理并启用域名面板时的两个 OpenRC 阻断点：复用 Alpine stream 模块自带的空配置块，修正入口服务函数被局部变量遮蔽的问题。已有自定义 stream 分流仍拒绝自动接管。

发布检查新增真实正式程序的 Alpine 3.23.6/OpenRC 安装测试：空机安装、失败遗留日志恢复、4 个 native-v3 旧服务导入、3 个外部出口、4 份旧客户端实际流量，以及 HTTPS 页面和静态资源与代理共用 443。HTTPS 测试使用已有测试证书，不调用公网 CA。
