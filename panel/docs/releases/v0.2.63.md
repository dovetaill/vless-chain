# v0.2.63

安装和日常运维由原生 Rust `chainctl` 接管，覆盖安装、升级、回滚、备份、卸载、服务维护、HTTPS、统一入口及旧配置迁移。

- 在线 Shell 引导校验发行包后运行 Rust；离线安装直接使用包内程序。
- 删除已替代的 Python 运维实现及其旧测试；保留构建、发行与集成测试工具。旧版本升级保留经过校验的兼容转交入口。
- 普通 CI 与正式发布执行相同的发行 smoke，覆盖本机接入、迁移、客户流量和额度、HTTPS，以及 OpenRC 新装与恢复。

升级会重启受影响组件，已有连接可能重连。配置、凭据和业务数据保留；仍建议升级前保存私有备份。
