# v0.2.6

将 REALITY 的内置默认目标改为微软网站。

- 默认目标由 `www.cloudflare.com:443` 改为 `www.microsoft.com:443`，默认 SNI 同步改为 `www.microsoft.com`。
- 同步前端表单、控制台节点创建与恢复、安装器本机接入及命令帮助，更新本机接入测试预期。
- 保留已保存的节点目标、SNI 和显式指定的安装参数；现有本机节点仍会将其已保存的目标带入新建代理表单。

提交前已通过前端类型检查、两项安装器定向测试及差异检查。当前环境到默认目标的 TLS 1.3、HTTP/2 和证书域名匹配检查通过；未进行中国大陆运营商线路实测，厂商在大陆提供业务不代表所有网络均可达。

升级：`sudo chainctl update --component panel --non-interactive`。安装器管理的本机 Agent 会一起更新并重启，现有连接可能短暂重连。升级不会自动替换已有节点的 REALITY 目标。
