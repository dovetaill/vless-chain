# v0.2.51

- 简化 chainctl 菜单：查看状态、启动、停止、重启直接作用于本机全部已安装组件，不再询问选择控制台还是 Agent。仅安装 Agent 的节点只操作 Agent；一个组件失败仍会尝试另一个组件，并显示失败原因。命令行显式 `--component` 保持原行为。
- 原生 Rust 安装模块暂仅参与测试构建，保留迁移测试；macOS 指标采集改用直接系统 FFI 声明，消除已报告的弃用接口警告。本版仍未将正式管理入口切换到 Rust。

升级后运行 `chainctl`，选 4 查看全部组件状态，选 6 重启全部组件，选 10 启动全部组件，选 11 停止全部组件；这些操作均不再弹出组件选择菜单。重启会短暂中断连接。

已安装控制台及本机节点升级：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --non-interactive
```

纯 Agent 节点在上述命令末尾加 `--component agent`。请等本版本正式 Release 发布后再执行。

`/opt/chain/releases` 存放实际可执行程序，并非可随意删除的备份目录。`current-panel` 和 `current-agent` 指向的版本必须保留；新版升级器会清理确认未使用的旧版。删除当前版本后，即使旧进程暂时还在运行，下次重启也会因找不到程序而失败。

验证：菜单回归覆盖双组件、单组件、未安装及一个组件失败的情况；完整安装器检查在非特权隔离环境运行。此前 Rust chainctl 编译无 warning，16 项测试通过；macOS 实际编译和运行以发行流水线为准。
