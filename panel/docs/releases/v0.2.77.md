# v0.2.77

- 设置页和多机总控会自动验收新提交的内核升级。总控最多同时处理 10 台 VPS，升级和验收共用这 10 个名额。提交 100 台时，每空出一个名额就补进下一台。单台失败或需要人工核对时，其余机器继续。
- 自动验收核对切换后的 Agent 心跳、配置应用结果和目标内核版本，并用升级前已发布的代理入口实际传输 HTTP。支持 UDP 的线路还会通过原入口发送 DNS 请求。任务详情会列出已测项目、空闲节点及需要人工核对的线路。
- 原链接验收失败时，任务保留失败原因，Agent 继续上报心跳并接收修复配置。内核切换本身失败时，符合安全回退条件的节点恢复原内核，其他节点隔离受影响的代理内核并保留管理通道。
- 设置页和多机总控会查询原维护任务的结果。关闭页面后后台仍会验收，重复查看同一任务不会再次安装内核。

升级时请先更新总控以及目标 VPS 的程序和维护执行器，再提交新内核批次。总控会提示哪些旧 VPS 需要先更新。既有暂停批次保留原任务记录。切换内核或重启 Agent 时，该节点上的现有连接可能短暂中断，无需重启 VPS。
