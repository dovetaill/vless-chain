# v0.2.67

- 修复旧部署升级后的服务迁移：已启用的统一 443 入口随 Agent 一起接管，维护进程在当前升级任务完成后切换到原生程序，保留已有配置和业务数据。
- 修正 systemd 环境文件路径生成，升级同时修复旧服务中的错误引号，避免 Agent 回退到默认数据目录。
- 修复 Alpine Nginx 隔离校验：保留日志格式、条件、级别及 `access_log off`，按原编译前缀解析相对动态模块路径。
- 为 0.2.61 等旧 Python 升级器保留必要的薄兼容入口，旧入口只转交原生 `chainctl`；新安装和日常运行继续使用原生程序。
- 修复通用 SH 在下载期间旧 Agent 重试时误读历史失败的问题；服务停止后重新记录请求基线，验证新进程产生的新请求。
- 已达到目标版本且有健康新心跳的历史升级失败记录默认折叠，原始任务详情保留；未恢复的故障继续显示。

旧网页升级过渡会在旧任务写入完成回执后接管服务，期间可能额外重启一次 Panel 与 Agent。建议保留升级前备份；应急修复程序会在正式升级时由发行包内原生入口接管。
