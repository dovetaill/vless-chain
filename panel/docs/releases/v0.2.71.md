# v0.2.71

修复 systemd `Type=simple` 下，维护程序在 Agent 真正执行前检查进程路径、误报“仍在运行旧程序”并触发安全停用的问题。启动阶段在原有超时内等待目标程序执行；确认后继续检查进程身份、运行环境和稳定性，不放行真正的旧进程或反复重启。

修复安全停用后恢复内核时未启动统一 443 入口监听的问题；切换和安全回退同时接管入口服务，并核对切换后产生的新配置请求和应用结果。

安装脚本的 `--package` 支持本地文件和 HTTPS 发行包地址，自动获取同目录 SHA256SUMS 并校验，明确指定包时使用包内安装器。不指定包仍使用默认 GitHub 流程。

已安全停用的部署先升级程序，再通过本机或总控维护入口重新安装安全内核。程序升级保留停用状态，内核升级仍需原链接实际传输验证。保留配置、节点身份和业务数据。
