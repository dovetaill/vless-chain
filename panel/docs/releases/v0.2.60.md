# v0.2.60

代理创建和编辑页面补齐连接凭据，支持迁入已有配置时填写原密码和 UUID。

- Shadowsocks 可选择 `aes-128-gcm`、`aes-256-gcm`、`chacha20-ietf-poly1305`，以及 SS2022 的 AES-128-GCM、AES-256-GCM，并填写对应原密码；新建默认仍为 SS2022 AES-128-GCM。
- VLESS、VMess、TUIC 支持指定或修改客户端 UUID。HTTP/SOCKS5 用户名，以及 Trojan、Hysteria2、TUIC 等协议的密码，统一显示在“连接凭据”区域。
- 新建时留空自动生成；编辑时空 UUID、密码和未指定的加密方式保留已有值。仅明确输入的新凭据会替换原值，密码的首尾空格与特殊字符不被表单裁剪。
- 保存、生成内核配置及导出链接使用相同凭据；非法 UUID、未知 SS 加密方式、不符合所选 SS2022 算法长度的 Base64 密钥会被拒绝。

保持原协议、地址、端口、加密方式及凭据，可继续使用原客户端配置。明确修改密码、UUID 或加密方式后，需要同步更新客户端；SS2022 密钥不能直接用任意传统 SS 密码替代。

## 验证

非特权独占目录中，4 项 Rust 定向测试通过，覆盖 5 种 SS 加密方式、8 种协议的凭据保存与导出、空值保留、显式修改及非法值拒绝。前端类型检查与生产构建通过；完整 `resource-flow.cjs` 浏览器回归通过，包括本次新增的 SS 密码和 UUID 创建/编辑流程。

浏览器夹具同时补齐此前内核维护功能的版本列表模拟响应，保留原权限与导航断言。所有测试进程、浏览器、监听端口、临时依赖、构建目录和截图已清理；未操作生产服务或修改生产权限。
