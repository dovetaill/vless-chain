# v0.2.62

调整 REALITY 新建默认值、目标推荐及发布检查，减少已知配置风险。

- 移除 Apple、微软等静态推荐，不再为新建节点预填目标；使用固定版本的美国院校公开目录作为候选来源，不扫描 IP 网段。
- 每次抽取少量官网，由节点检查 TLS 1.3、H2、证书、DNS 地址及 Cloudflare 特征；无法获取官方 Cloudflare 网段时停止推荐和发布。
- 新建 REALITY 默认公网 TCP 443；端口冲突时报错，不自动换用高位端口。明确填写其他端口及编辑已有端口仍受支持。
- 发布前重新验证目标及完整 REALITY 握手、回落过滤，失败保留草稿；移除未验证配置的强制发布入口。
- 修复 Xray 26.10.21 私网目标限制导致诊断误报：仅在临时诊断配置中放行精确的回环测试端口。
- 发行构建包含候选数据，并附带目录来源的 MIT 许可证。

## 升级与限制

面板和 Agent 均需升级；旧 Agent 不支持新的发布检查，将阻止相关 REALITY 配置下发。已有配置不自动改端口或目标；节点配置变更发布时会重新检查其中的 REALITY 目标。

公网入口 443 与目标网站 443 是独立配置。院校目录仅提供候选，检测通过不代表抗封保证；Cloudflare 排除基于检测时的解析地址及响应，无法保证未来 DNS/CDN 不变化。本版本不自动部署到生产服务器。

## 验证

非特权隔离环境中的候选过滤、默认端口与冲突、发布结果校验及凭据定向测试通过，Rust 编译检查、前端类型检查、构建和浏览器交互检查通过。真实 Xray 26.3.27 与 26.10.21 均通过回环环境中的 REALITY 握手、数据通路、回落过滤及错误 SNI 拒绝测试。

未验证中国大陆抗封效果；三平台发行构建和安装验收由标签工作流执行。临时测试进程、监听与编译产物已清理，核对的既有文件属主、属组和权限未变化。
