# v0.2.15

- 修复通过 curl 管道安装时漏下载 `chain_ingress.py`，导致证书申请成功后安装失败、HTTPS 配置回滚的问题。
- 安装或中断后重试时，复用同域名且未过期的已有证书，不执行 Certbot 申请和 HTTP-01 自检；即使临近过期也复用。证书不存在或已过期时才申请。已有证书损坏、域名不匹配或私钥异常时停止并报错，避免误触发重新签发。
- 重试仍会恢复 HTTPS 站点和自动续期配置。日常定时续期机制保留，按 Certbot 的正常策略在到期前续期。

已有安装升级：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --component panel --non-interactive
```

曾在证书申请成功后中断的安装，使用新版入口显式重新配置原域名：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- install --domain 你的面板域名 --local-host 服务器公网IPv4
```

无需删除 `/etc/letsencrypt` 中的证书，也无需卸载。安装器保留已有数据和凭据；恢复或升级期间控制台及本机节点会短暂重启。

回归测试覆盖临时下载目录的模块导入、真实 PEM 证书的到期/域名/私钥检查，以及签发后中断、重试复用和过期后重新申请的流程。测试中的签发和系统服务操作均为模拟；真实申请由服务器上的 Certbot 执行。四平台原生构建和安装冒烟测试由标签发布工作流执行。
