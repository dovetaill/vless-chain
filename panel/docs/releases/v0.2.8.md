# v0.2.8

调整 Dashboard 的留白与信息布局，减少查看服务器实时状态所需的滚动。

- 标题、说明文字及主机卡片增加明确的内边距，解决内容贴边。
- 桌面端服务器状态与近 30 天代理流量并排，CPU、内存、磁盘及网卡收发分组展示。
- 手机端顶部统计卡改为两列，收紧卡片、图表及经营总览表格的间距。

已通过 TypeScript/Vite 构建和 5 种屏幕尺寸的浏览器检查。单台主机在 1024×768、1280×800、1366×768 下的实时状态与流量图均完整显示在首屏；另已检查离线、过期或缺失采样、空主机列表、长主机名称及逐日流量明细。多主机、长代理列表或较小屏幕仍可能需要滚动。

升级：`sudo chainctl update --component panel --non-interactive`。安装器会备份并升级、重启本机面板与 Agent，保留现有数据和凭据；代理连接会短暂重连。本次不改变流量计量或出租业务逻辑。
