# v0.2.35

- Web 新增「日志与诊断」：代理菜单、监控告警和总控 VPS 详情均可打开。支持持续跟随、暂停、来源/线路筛选、归档读取和脱敏下载；关闭弹窗停止请求。
- 应用与代理内核日志轮转、压缩、自动清理：最多保留 3 天，面板与 Agent 各 50 MiB，总计 100 MiB。系统 journal 仍由系统管理。
- 增加出口与整链分段检查。详细诊断窗口 10 分钟到期；临时诊断内核每次检查后退出，不重启运行中的代理。
- REALITY 目标在实际 Agent 上验证握手；发布前检查新增目标。明确失败阻止下发，无法验证时要求显式确认。各跳 SNI 无需相同，但须匹配各自目标。
- 增加时间偏差、自动同步状态和告警。Web 校时需确认，作用于当前面板所在 VPS，保持时区；不会自动修改其他远程 Agent 时间。
- `chainctl logs --follow` 支持持续查看，`--log-source` 可选 application、xray、mihomo 等来源。
- 修复删除最后一组迁移配置后缺少待下发入口，以及迁移变更未计入重启影响的问题。
- GitHub Actions 增加依赖与编译缓存；仅 CI 保留缓存，本机构建仍清理。首次冷缓存构建不会立即提速。

升级：正式 Release 附件发布完成后执行 `sudo chainctl update`。总控及各 VPS 的面板、Agent 都需升级，旧 Agent 会显示升级提示。

自测：打开「监控告警 → 日志与诊断」，切换来源、暂停/继续、读取归档、下载片段；从代理菜单执行分段检查；从总控 VPS 详情读取远端日志。启用自动校时会修改对应 VPS 系统时间，请核对确认框中的作用范围。

浏览器回归用例：`panel/tests/diagnostics_browser.py`（真实隔离面板/Agent；故障响应及校时动作模拟），另有 50 台 VPS / 500 条代理总控交互测试。测试环境不接管线上服务。
