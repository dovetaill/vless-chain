# v0.2.5

完善 VLESS 多组合接入、REALITY 目标检测、网站回落及统一 443 域名分流，修复多协议链式代理和分享配置问题。

- 展示和配置 REALITY 目标地址与 SNI，可检测 TLS 1.3、证书域名匹配及 H2。
- 一次创建 REALITY + Vision、TLS + Vision、REALITY + XHTTP、TLS + XHTTP，各自导出对应链接和 Mihomo 节点；XHTTP 不携带 Vision flow。
- TLS + Vision 支持内置网站或 HTTP/HTTPS 网站回落。执行 `sudo chainctl ingress-enable` 后可按 SNI 共用 TCP 443，保留已有 Nginx 网站和客户端 IP；升级本身不自动启用 443 接管。
- 修复 HTTPS 分享链接丢失 SNI、SS 与 HTTPS 链式兼容问题、Hysteria 2 连接路径复用及 UDP 分片问题。HY2/TUIC 接入和包含 SS、HTTPS、HY2、TUIC 的出网链由受管 Mihomo 执行。
- 修复 REALITY 冷启动首次连接失败，为当前 Xray 目标采样预留启动时间；内部监听端口避开系统临时连接端口范围。
- 按完整路径计算 UDP 能力，分享、导入及订阅保留 `udp: false`；前置路径不支持 UDP 时拒绝保存 HY2/TUIC 链路。
- 改善证书说明间距及启动失败诊断，兼容升级前保存的 HY2 自动证书配置。

已完成本机隔离验证：27 项 Rust 单元测试、前端类型检查及构建、浏览器表单流程；13 种协议/传输配置、169 种有序双协议组合及两条四跳混合链，共分批覆盖 184 项，其中 180 项有效链路 TCP 和逐跳计量通过，148 项 UDP 在支持范围内通过，4 项不支持的组合正确拒绝。另验证面板探测、导入导出、嵌套订阅、四种 VLESS 接入、网站回落及 Nginx SNI 分流。未覆盖所有客户端版本和跨公网环境。

HY2 保留上游 4096 字节 UDP 数据报限制。IPv4 目标下，HY2 → 本项目默认 SS2022 的双向业务载荷上限为 4038 字节，HY2 → SOCKS5 为 4086 字节，边界成功和超限失败均已验证；不同地址或封装会影响可用大小。本版本不修改上游内核。

升级：`sudo chainctl update --component panel --non-interactive`。安装器管理的本机 Agent 会一起更新并重启，现有连接可能短暂中断；远程 Agent 需分别更新。统一 443 需另行执行上述启用命令，并为不同入口使用不同 SNI。
