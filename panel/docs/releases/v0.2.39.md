# v0.2.39

- `chainctl` 菜单更新一次处理本机已安装组件与管理命令，不再重复选择组件；面板已更新但 Agent 更新失败时明确显示部分完成和重试提示。
- 更新时自动检查系统时间同步，复用已有时间服务，必要时安装支持的时间服务，保持现有时区。状态查询超时或同步失败会提示原因并继续组件更新。自动校时目前依赖 systemd/timedatectl，其他系统会提示不支持，不误报同步成功。
- 菜单使用终端行编辑，支持左右键、退格、Delete；数字编号加回车选择，空白回车使用默认项，不记录输入历史。缺少 readline 时，菜单编号改为不回显输入并忽略方向键转义序列。
- 组件和日志来源增加返回选项，接入码输入支持 `0` 取消；子操作中 Ctrl+C 返回主菜单，持续日志 Ctrl+C 停止跟随后返回。
- 日志可选择最近 100 行或持续查看；Web 控制台只展示服务和应用日志，内核日志在 Agent 下查看。迁移配置 UUID 错误显示中文提示。
- 已安装组件再次进入安装向导前说明重装和重启影响，默认返回；统一 443 启停增加影响说明、确认和完成提示。登录令牌缺失、数据库错误不再产生循环指引或直接退出菜单。
- 回滚保留手工 HTTPS、端口、仅面板安装等元数据；备份失败或中断会删除本次残缺归档，保留已有备份。
- 新增菜单回归与真实 PTY 测试并接入发布检查，覆盖按键编辑、缺少 readline 的降级、接入码不回显、日志子进程中断及菜单返回。

验证：非特权独占目录中完整脚本检查 148 项通过，之后补充 5 项真实 PTY 回归，更新后的菜单测试 12 项通过；额外验证旧版安装器升级新归档、校时查询超时与 Agent 更新失败组合、备份中断清理。真实隔离 Nginx 校验与 reload 通过，宿主机验证副本中的两个 Nginx 夹具额外指定独占 lock_file。测试进程、日志、数据库、证书、临时安装树均已清理，未操作生产服务、修改生产权限或系统时间。正式三平台构建、安装验证与附件发布结果以本版本 Actions 为准。

## 已安装用户升级

等待本版本 Release 附件完整发布后，在总控和需要升级的 VPS 分别执行：

```sh
sudo chainctl update
# 仅安装 Agent 的机器使用：
sudo chainctl update --component agent
```

旧版安装器首次升级后，退出旧菜单并重新运行 `chainctl` 才会加载新版交互逻辑。若希望本次升级立即使用新的时间同步流程，可以使用最新安装脚本执行更新：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/v0.2.39/scripts/install-server.sh | sudo sh -s -- update
# 仅安装 Agent 的机器：
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/v0.2.39/scripts/install-server.sh | sudo sh -s -- update --component agent
```

引导脚本从仓库 main 的同一提交获取安装器，发行程序来自最新正式 Release；上述入口不是锁定全部依赖到 v0.2.39 的离线安装。通过旧命令升级的用户也可在重新打开新版 `chainctl` 后再执行一次更新，触发时间同步检查。更新与备份可能短暂中断对应服务，请选择维护时段。

## 自测

1. 重新运行 `chainctl`，确认已安装组件显示 `0.2.39`。输入 `12` 查看帮助，使用左右键、退格、Delete 编辑编号；输入空格后回车应采用当前默认项，方向键不应显示 `^[[A` 等字符。菜单按编号选择，不使用上下键切换选项。
2. 双组件机器进入状态或重启的组件选择，输入 `0` 或按 Ctrl+C，应回主菜单且不执行该操作。菜单 `1` 对已安装组件提示重装，直接回车应取消。
3. 菜单 `5` 选择服务日志，分别检查最近 100 行与持续查看；持续查看按 Ctrl+C 应回菜单，不遗留 `journalctl`/`tail` 跟随进程。面板不应显示 Xray/Mihomo，Agent 应显示内核来源。
4. 在 systemd 机器更新后执行 `timedatectl show -p NTP -p NTPSynchronized -p Timezone`。正常结果应为 `NTP=yes`、`NTPSynchronized=yes`，时区保持原值。两台机器执行 `date -u` 对比；如果仍未同步，查看更新输出中的具体失败原因。
5. 菜单 `7` 备份应输出归档路径，文件权限应为 `600`。回滚、重置登录安全、确认启停统一 443 和卸载仅在测试 VPS 验证；日常生产自测可进入相应确认页面后取消。回滚只恢复程序版本，不恢复旧数据库。

本版本不改动总控网页的过期判定和图表单位。系统时间恢复后仍显示异常时，应继续检查同步错误和采样时间，不能将组件升级成功视为全部链路正常。
