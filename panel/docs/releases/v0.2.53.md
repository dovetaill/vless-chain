# v0.2.53

- 支持 Alpine/OpenRC 的 Web 维护。安装器创建并启用 `chain-maintenance` 服务，由其监听仅允许 root 与面板用户访问的本机 Unix socket；网页和总控继续使用原有维护协议。
- OpenRC 重启及状态检查使用 `rc-service`，升级仍使用正式发行包校验及现有组件升级流程。安装器不会停止正在执行升级的维护服务；任务凭据持久化，维护服务重启后仍可查询，不自动重放中断任务。
- 修复任务结束时清理进程组可能误停 OpenRC 新启动服务的问题。卸载时清理归属已确认的维护服务、运行目录与日志。
- 增加真实 Alpine 容器回归并接入发行检查，覆盖安装与修复、面板用户调用、非授权用户拒绝、整套重启、任务幂等及维护服务重启后的结果查询。

验证：非特权安装器检查 176 项中 173 项通过，3 项因本地缺少 Nginx 跳过；新增卸载检查通过。独立 Alpine/OpenRC 容器测试通过，测试服务及容器、临时文件已清理，未修改生产服务。升级命令分发与版本校验已做模拟测试，真实发行包经 Web 升级的完整流程尚未端到端验证；三平台构建及发行安装验证以 Actions 为准。

## 已有 Alpine 机器如何启用

等待 0.2.53 正式 Release 发布后，在装有远端面板的 Alpine 机器上通过 SSH 执行一次：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sh -s -- update --non-interactive
```

上述命令适用于 root。首次更新用于安装此前不存在的维护服务；之后可在网页“版本与维护”或总控执行后续升级和重启。纯 Agent 安装本身没有远端面板，不会因此新增 Web 维护入口。

运行 `rc-service chain-maintenance status`，确认服务已启动；等待总控同步后，“尚未安装维护组件”应消失。先在单台机器验证 Web 整套重启，确认面板恢复访问、Agent 恢复上报，再批量操作。

本版仍使用现有 Python 管理入口，Rust 迁移尚未完成。
