# v0.2.38

- 新增共享资源额度页面：按服务器或外部代理组统一设置周期流量、上下行合计带宽、重置日期、小时及时区；资源耗尽后限制关联代理。
- 租户流量按上传与下载合计计量，直连倍率为 1，已知链式路径按节点数量计费。资源额度不重复乘租户倍率。
- 支持外部代理批量导入、按相同域名或显式 IP 识别分组候选，以及手动分组；已有分组不会被自动覆盖。
- 新增网站规则库、严格域名白名单、禁用端口、UDP 策略和并发连接限制。55 项预设均可生成有效规则，其中 46 项来自外部来源、9 项使用内置明确域名列表。外部来源支持定时下载与手动或自动应用；内置规则需手动应用。
- 修复 SS2022 → Hysteria2 的 UDP 回程：增加仅本机监听的兼容转接，保持出口、完整链路和计费倍率不变。
- 补齐旧 Agent 首次发布 UDP/端口限制时的能力校验；总控支持远程管理资源、规则、访问策略与外部代理分组。
- 统一资源带宽的上下行合计说明，修复时区输入框标签关联；更新项目 README 和使用说明。

验证：前期隔离主从全流程验证及本次五项修复的定向回归记录分别见 `panel/test-report-2026-10-20.txt`、`panel/fix-report-2026-10-20.txt`。修复后 27 项 Rust 定向测试通过；6 种相关链路的真实 TCP/UDP 与各跳计量通过；HTTPS 总控转发、55 项规则下载或载入并应用、真实浏览器远程操作、TypeScript 检查及构建通过。测试进程、容器和临时产物已清理。正式三平台构建、安装验证与公开附件发布结果以本版本 Actions 为准。

注意：资源计量覆盖本系统代理业务载荷，不等同于服务商全网卡账单。严格白名单要求客户端传递域名；并发连接限制不是设备识别。规则可应用不代表已验证付费服务解锁、全部站点功能或跨地区网络质量。旧 Agent 需升级后使用新增资源和访问限制；资源额度租约失效时关联流量会停止。

升级：等待正式 Release 附件发布完成后，使用支持维护的 Web 页面或 `sudo chainctl update`。本次发布不直接升级当前运行的生产服务。
