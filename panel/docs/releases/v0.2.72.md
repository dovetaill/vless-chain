# v0.2.72

- 内核下载或预检失败时保持现有服务及原停用状态，不再因此停止正在工作的 Agent。
- 重启维护须通过持续进程检查，避免启动后立即退出仍报告成功。
- 总控不再将排队或失败任务显示成维护完成；重启期间非 JSON 响应保留 HTTP 状态，沿用原任务 ID 查询。
- 新总控阻止向存在 EPERM 缺陷的旧版本下发内核更新；已安全停用且不能自行升级的旧维护程序显示一次性恢复步骤。

已停用的 v0.2.67–v0.2.69 无法仅靠旧 Web 维护程序完成程序升级。先在该 VPS 使用新版安装器更新程序，再返回面板更新安全内核并验证原链接；程序更新不会自行清除停用标记。

```sh
curl -fsSL https://chain.bareai.io/install-server.sh | sh -s -- update --package https://chain.bareai.io/releases/v0.2.72/chain-panel-0.2.72-linux-x86_64.tar.gz --non-interactive
```

该命令适用于 Linux x86_64；其他架构使用对应 GitHub 正式附件。旧版复现证据与验证边界见 `docs/verification/v0.2.67-web-upgrade.md`。不会把程序版本更新、Agent 心跳或空闲服务存活当作客户原链接传输验证。
