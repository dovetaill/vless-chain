# v0.2.76

- 修复 TCP 持续单向传输满 300 秒时被断开的问题。连接按双向空闲时间回收，半关闭后允许另一方向传完。低速线路上的并发传输轮流取得带宽，等待本地限速的时间单独处理。
- 代理线路默认并发上限为 4,096，最高可配置为 20,480。已有显式限额继续生效，节点根据文件描述符和可用内存设置保护额度。高于旧 Agent 能力的设置需要节点升级并上报新心跳。
- 网关、计量桥和网站监听遇到临时错误时独立重试，必要时重新绑定受影响的端口。节点上报持续错误，其他监听和已建立连接可继续工作。
- Mihomo 启动时验证本次进程持有的 TCP 和 UDP 监听。关闭诊断日志或保留历史监听错误均可正常启动。
- 自动 TLS 证书通过域名、密钥和有效期检查后即可投入使用。续期在后台执行，失败会上报并重试。已保存配置恢复失败时，Agent 保留心跳和接收修正配置的能力。
- 流量账本写入失败时，Agent 拒绝转发尚未确认计费的数据并保持心跳。存储恢复可写后，Agent 按已落盘数据恢复计量。无关资源的额度申请可以独立完成。
- 心跳与流量历史独立上报。面板收齐分页并保存成功后才替换上一份完整统计。单页最多 256 KiB，每节点未完成快照最多暂存 64 MiB，超限会报告同步错误。
- 首次安装使用严格的 `umask 077` 时，新建的程序和证书验证目录允许服务账户进入。已有目录的权限及私有凭据权限均保留。

升级时先更新 Panel，再更新 Agent，可在节点更新后启用分页上报。新版与 v0.2.75 支持交叉连接，配合旧 Panel 时沿用原有整包上报及其请求大小限制。替换 Agent 进程会中断该节点当时的代理连接。
