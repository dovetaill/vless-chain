# v0.2.61

补齐本机与批量网络算法设置，让管理员可以在网页中为本机和远端 VPS 选择 BBR / FQ，并查看系统默认值与网卡实际队列。

- “设置 → 版本与维护”新增本机“网络算法 / BBR”入口；多机总控的 VPS 页常驻显示本机与批量入口，可将本机加入同一批次。
- 批量可选项仍取各台机器支持选项的交集，逐台记录结果。重新打开失败任务后，可以正确选择失败的本机重试，不带上已成功的远端。
- 本机网络设置仅管理员可操作。运维成员看到禁用按钮及权限说明，财务和只读成员不能进入设置或多机总控；保持现有后端权限。
- 保存 TCP 默认算法与默认队列后，新版维护组件尝试在线替换内核自动创建的默认队列，保留 `mq` 多队列根结构及虚拟设备队列；自定义队列、限速或流量过滤规则不被覆盖，跳过与失败原因显示在结果中。

## 生效范围

无需重启服务器或服务。已有 TCP 连接和监听器不会自动切换拥塞算法，TUIC / Hysteria 的拥塞控制不受此设置影响；在线替换队列可能短暂丢包，不承诺固定提速。旧 VPS 需升级面板及维护组件后才能使用在线队列切换。

系统默认值保存成功后，个别网卡未切换不会撤回已保存的默认值，也不会声称全部网卡已经生效。请核对每台机器显示的实际队列及跳过原因；本次仅自动替换可识别的内核默认队列，保留已有自定义配置。
