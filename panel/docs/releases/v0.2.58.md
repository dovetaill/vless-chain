# v0.2.58

v0.2.56、v0.2.57 均被 CI 拦截，未生成正式发行包。本版保留引导下载测试修复，并修复 OpenRC 测试添加精确回环放行时丢失 `direct` 出站标签的问题，新增路由目标存在性断言。官方 Xray 的实际传输回归已复现缺标签错误，并确认修复后同一客户端、UUID、密钥和端口可以正常传输。

- 发行包默认更新为官方 Xray 26.10.21、Mihomo 1.19.33，下载核对固定版本、架构附件来源与 SHA256。
- “设置 → 版本与维护”支持分别选择 Xray、Mihomo 的准确版本；预发布需要主动允许。已独立选择的版本在后续面板升级时保留。
- 主控支持逐台批量升级 VPS 内核，每台须完成原链接实际传输确认后继续；失败或结果未知暂停后续节点，重复查询不会重复安装或跳过失败节点。
- 普通升级失败恢复原内核；安全更新默认禁止回退未确认安全的版本。无安全回退版本时停用代理并保留管理面板，机器重启也不会自动解禁。
- 升级不重新生成 UUID、REALITY 静态 X25519 密钥、端口或 VLESS 链接参数，不回退业务数据库。历史 JSON 与 WS 配置一并预检。

## 升级与兼容

先更新主控及 VPS 的维护组件，再选择一台试点。确认实际内核版本、客户原链接传输及需要的 UDP 功能后，提交其余 VPS 的批次。更新客户端软件可能仍然必要；保留 X25519 密钥不代表兼容所有旧客户端握手。

独立内核预检要求 Linux Landlock ABI 3+ 与 seccomp，以实际 Agent 非 root 身份在临时目录验证，限制写入、权限修改及网络访问。不支持隔离或配置依赖尚未缓存的在线资源时拒绝切换；安全更新没有安全回退版本时，下载或预检失败也会停用代理。

Xray 新版的 Freedom 出站默认阻止 VLESS 等代理访问私网地址，本项目保留该保护。历史配置如确需访问内网，应单独核对必要的目标地址与端口规则。版本与配置预检、自动 HTTP 检测均不能替代实际客户连接及 UDP 验收。

## 验证

非特权独占环境中，Python 内核维护 14 项、维护执行器 14 项、安装更新 4 项、平台附件与清理 2 项定向测试通过；Rust 主控 18 项测试及后续批次恢复回归通过，Agent 与管理命令编译检查通过。

前端类型检查、生产构建与模拟接口浏览器流程通过，覆盖本机内核确认及主控转发确认。官方两种目标内核通过 SHA256 校验和隔离配置预检；Xray REALITY 大证书握手及真实传输通过。测试使用精确回环端口放行，生产配置不随测试改变。

发布前补齐集成测试对新版默认私网拦截的适配，仅放行测试的临时目的端口。三平台正式包构建及完整安装、迁移、套餐验收由标签工作流执行，以最终 CI 结果为准。本次发布不自动部署生产服务，不修改生产权限。
