# v0.2.2

创建代理、配置中转、复制客户端节点配置，现在集中在同一流程。

- 默认进入代理列表，移除总览、网站反代入口及冗余说明。
- 支持在创建过程中启用本机或通过 SSH 添加远程服务器，保留已填写的内容。
- 明确区分入口、中转和出口；保留独立 TCP/UDP 端口转发。
- 增加 VLESS TLS + Vision，分享提供单条 Mihomo YAML、协议链接和二维码，不生成分流配置。
- 本机组件随控制台管理，支持异常退出清理与恢复；已有系统 Agent 通过明确身份复用。

升级顺序：先执行 `chainctl update --component agent --non-interactive`，再执行 `chainctl update --component panel --non-interactive`。升级会重启对应服务，连接可能短暂中断。

已完成前后端构建、Rust 定向测试、浏览器流程、真实三跳代理、Mihomo 导入、SSH 安装及本机恢复验证。公网证书签发未实测；网页启用的受限本机组件使用低端口仍需系统权限。

API 变更：`/api/lines/{id}/export` 的 `node` 改为单节点 YAML 列表项，移除 `config` 字段。现有网站配置不自动删除，网页不再提供网站反代管理入口。
