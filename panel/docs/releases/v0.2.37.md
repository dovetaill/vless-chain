# v0.2.37

- Web 页脚显示面板版本，“设置 → 版本与维护”展示面板、Agent 及发行包内的 Xray/Mihomo 版本，支持检查最新正式 Release、升级并自动重启、整套重启。
- 总控支持逐台整套重启子 VPS，并检查远端是否支持该操作；任务失败或结果未知时暂停后续机器。
- 升级会更新已安装的面板和 Agent，自动重启相关服务及项目独立 HTTPS 服务；Agent 同时重启其代理内核。保留 Agent 原有 HTTPS 或其他面板接入关系与身份凭据。
- 页面保存维护任务 ID，面板重启、重新登录或刷新后继续查询原任务，避免重复提交；升级后检查所有原已安装组件的目标版本，拒绝自动降级。

验证：维护组件 8 项 Python 测试、安装器 2 项定向测试、总控 API 6 项 Rust 测试、TypeScript 检查、前端构建及维护页面浏览器测试通过。另以隔离的 systemd 容器运行一个总控和一个子节点，使用本地 Release 测试源完成真实安装、配对、代理发布、远程升级和重启、浏览器本机升级和重启；核对面板、Agent、Xray、Mihomo、独立 HTTPS 服务 PID 变化及凭据保留，验证错误校验和拒绝升级、断线后任务恢复、1.44 MB 代理传输及 541 KB JS 完整传输。测试环境与编译产物已清理。正式三平台构建、安装验证与公开附件发布结果以本版本 Actions 为准。

范围：网页维护支持 Linux systemd；OpenRC、macOS 和纯 Agent 安装暂不支持。共享 Nginx 仅按安装流程需要重载配置，不重启宿主机。升级会短暂中断该服务器的代理连接；失败时保留组件结果，不回退业务数据库。旧版 VPS 需先升级，再使用新增的整套重启操作。

升级：正式 Release 附件发布完成后，可从支持维护的总控或本机 Web 页面升级；也可执行 `sudo chainctl update`。
