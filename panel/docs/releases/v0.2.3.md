# v0.2.3

代理创建统一为本机监听，创建时直接选择直连或按顺序配置链式代理。

- 自动生成名称、空闲端口和凭据，无需选择入口服务器；支持分别创建多个本地代理。
- “服务器”改为“外部代理”，支持协议链接及受支持的 Mihomo 单节点 YAML/JSON 导入，分享提供协议链接、二维码和 Mihomo 节点配置。
- 链式配置可选择已导入的外部代理或已启用并发布的本地代理，检查循环引用和删除依赖。
- 移除端口转发页面、新增中转入口、购买中转入口选项及 Web SSH 安装功能；远程机器自行登录安装。
- 安装时准备 Nginx/Certbot；创建代理填写本机域名后自动申请 TLS 证书，复用 Nginx 验证目录，并支持证书续期。
- 修复本机节点身份恢复、链式出站配置及默认 REALITY 握手目标。

已验证前后端构建、相关 Rust 测试、脚本检查、浏览器创建/编辑/禁用/删除与导入分享流程，以及真实 Xray 多跳请求和公网证书签发。VLESS REALITY、VLESS TLS、HTTP、SOCKS5、Shadowsocks 2022、Trojan 均已通过实际请求验证。

升级：`sudo chainctl update --component panel --non-interactive`。已由安装器管理的本机 Agent 会一起更新并重启，现有配置与登录令牌保留；连接可能短暂中断。远程机器需在各自机器上更新。

兼容性：不再接受新增端口转发、中转入口与 Web SSH 安装请求；已有旧配置不会自动删除。Mihomo 导出为单节点配置，需加入现有客户端配置；未验证所有客户端版本，不支持的导入字段会明确报错。
