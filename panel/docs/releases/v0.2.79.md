# v0.2.79

- 专用代理端口支持原生 IPv6 接入，SOCKS5 UDP 关联按客户端地址族回包。在只有 IPv4 或只有 IPv6 的主机上使用可用的地址族。
- 改善接近满载时的连接回收。TCP 两端均空闲时保留 300 秒窗口，托管 Xray 在一端结束发送后的单向空闲窗口缩短至 30 秒。节点根据文件描述符、物理内存和服务组内存上限控制并发，为内核及其他进程预留四分之一内存。多个节点串联时，名额会逐段释放。
- 修复共享额度申请在并发扣费时可能自锁的问题。硬额度在转发前持久预留，异常重启后按预留上限恢复。流量明细每 5 秒合并写入，面板对订单等业务提交使用 SQLite WAL 和 FULL 同步。备份应在停止 Agent 后包括整个数据目录。
- 共享池与客户套餐从 16 MiB 开始申请额度。先升级 Agent 时，v0.2.78 面板仍可按原窗口续租。面板也升级后，窗口可按用量增长到 128 MiB。

**升级与容量**　先升级 Agent，再升级面板并应用配置。用原有客户端链接确认 TCP、UDP 和节点新心跳。双节点 SOCKS5 → Shadowsocks 2022 压测中，1,850 条在线会话完成了 27,750 次回显。同期另开六条下载，180 秒平均 407.58 Mbps。公网首包仍可能超时，单条双节点链持续 1 Gbps、双节点串联 2 万并发及多日满载均未验证。需要依靠 TCP 半关闭触发最终响应的应用仍有兼容限制。
