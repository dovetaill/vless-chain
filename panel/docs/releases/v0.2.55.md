# v0.2.55

- 主控支持为单台或批量 VPS 检测、选择 TCP 拥塞控制算法和默认队列，默认推荐 BBR + FQ。显示每台内核、当前设置、可用选项及网卡实际队列；批量选择取各台支持选项的交集。
- 设置通过现有维护任务下发，校验算法、队列和目标能力，持久化到专用 sysctl 与模块加载文件。失败时尝试恢复原设置并报告恢复结果，重复任务保持幂等。
- 补齐 `/admin#fleet`「所有代理」中的单条启停、限额、分享与二维码、访问策略、探测、诊断、预览应用和删除操作，并支持按来源 VPS 批量导出、限额及删除，显示各台处理结果。
- 复用现有线路弹窗和远端接口，保持客户套餐线路的删除限制；远端代理分享提供连接与 Mihomo 导出。

## 使用与边界

先升级主控及需要设置的 VPS，在 VPS 列表或详情中打开网络调优；多选 VPS 后可批量下发。目标必须上报相应维护能力，旧版本需先升级。

本次只选择机器已有或可加载的算法、队列模块，不安装或替换 Linux 内核，不自动重启。仅修改 TCP 拥塞控制与默认队列两个系统设置；现有连接、监听器和网卡队列不会被强制重建，界面分别显示默认值与实际队列。其他调优工具可能覆盖这些默认值，实际效果取决于链路与负载，不承诺固定提速。

远端财务、客户管理与订阅接口不在本次范围内；已有权限检查继续生效。

前端类型检查、生产构建及模拟接口的浏览器流程通过，覆盖跨 VPS 同名线路的操作定位、远端弹窗、批量部分失败、算法交集与下发参数。未连接真实 VPS 修改内核参数或进行公网提速测试。
