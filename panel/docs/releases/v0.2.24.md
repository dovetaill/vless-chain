# v0.2.24

修复旧代理迁移时控制台无法启动、原 REALITY 配置导入不完整，以及 NAT 后本机节点连接检查超时的问题。

- 延迟配置 ACME 时也会先创建 systemd 要求的可写目录；已有目录的属主和权限保持不变。
- 导入保留 REALITY 本机目标、回落限速参数和原认证信息，兼容 `method: raw` 及指向默认直连出口的路由规则；编辑线路时保留已导入的回落限速。
- 旧配置无法完整导入，或本机 REALITY 目标会随旧服务一起停止时，取消切换并保留旧服务；完整导入后再停用旧服务，发布失败时恢复。
- 本机节点连接检查使用本机入口及实际监听端口，保留认证和 SNI；公网分享链接不变。探测结果标明本机入口，不代表公网 NAT 入站或 UDP 已验证。

已安装用户可运行 `sudo chainctl update --latest --non-interactive` 升级控制台与本机节点。升级会重启相关组件，代理连接可能短暂中断；既有线路和连接凭据保留。
