# v0.2.11

安装与运维入口支持 Linux（systemd / OpenRC）和 macOS 14+，CPU 支持 x86_64 / ARM64。

- Linux 发行包改为静态 musl 构建，兼容 Alpine；安装依赖支持 apt、apk、dnf、yum、pacman 和 zypper。系统需提供 Python 3.10+，旧发行版可能需要先自行安装兼容版本。
- macOS 使用 launchd 管理服务，通过 Homebrew 安装依赖；从已安装 Homebrew 的普通管理员账户执行 sudo 安装命令。
- 适配服务账户、升级与回滚、Nginx HTTPS 与续期、网卡和端口检查；补充 macOS 的运行指标、核心进程清理及端口分配。
- 发布流程分别构建并验证 Linux / macOS 的两种架构，四个平台全部成功后才公开 Release。

已完成本机验证：68 项脚本测试、定向 Rust 测试及 Linux 程序编译。各平台的原生构建与安装冒烟测试由本次发行工作流执行；未在所有 Linux 发行版及真实 macOS 服务环境逐一安装验证。Windows 暂不支持。

首次安装：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh
```

从旧版升级请使用新版安装入口，以识别新的静态发行包：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --component panel --non-interactive
```

安装器备份并升级、重启控制台和匹配的本机 Agent，保留配置、业务数据和凭据；连接可能短暂重连。独立节点将上述 component 改为 agent。升级完成后可继续使用 chainctl 管理服务。
