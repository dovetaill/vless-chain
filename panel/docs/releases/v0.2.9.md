# v0.2.9

将网站首页改为客户公共查询页，并修复前端公共样式与窄屏布局。

- 根地址直接展示代理服务查询，不请求管理员状态。管理后台移至 `/admin`，首页提供「管理登录」入口；后台书签请使用 `/admin#lines` 等新地址。原有 `/query` 和私密查询链接继续可用。
- 按 Metronic 的样式层级组织表单与表格默认样式，修复全局规则覆盖筛选宽度、控件字号和局部间距的问题。
- 统一卡片标题的上下留白、标题换行及卡片收缩行为。代理列表的搜索和三个筛选在桌面同排，手机按可用宽度换行。
- 收款记录空状态补齐内容内边距，表格保持名称等普通字段可读；修复外部代理按钮、Passkey、订阅长名称和弹窗说明的窄屏边界问题。

验证：TypeScript/Vite 构建通过；五个后台页面覆盖 1440、1024、768、390、320 像素宽度，公共首页覆盖 1440、390、320 像素，检查标题留白、筛选对齐、控件字号、按钮边界及页面溢出，并检查空数据、长名称和客户弹窗。已有出租管理、公共查询及代理创建浏览器流程通过。服务端公共与管理入口的定向 Rust 测试通过，编译目录与测试进程已清理。

升级：`sudo chainctl update --component panel --non-interactive`。安装器会备份并升级、重启面板及本机 Agent，保留配置和凭据；连接会短暂重连。此次仅调整页面入口与样式，不改变计量、收款或权限校验逻辑。窄屏多列表格仍通过表格区域横向滚动查看全部字段。
