# v0.2.52

- 修复空节点的后台监控误报：Agent 在线、报告配置已应用、没有期望或已运行的配置版本，且没有普通线路或迁移配置时，不再因代理内核未运行触发“代理运行组件”告警。
- 已存在的空节点运行告警会在下一次监控检查时自动解除。Agent 离线、执行错误、配置未应用或已有代理配置时仍保留原有监控行为。

验证：非特权隔离环境运行 8 项监控定向测试，全部通过；覆盖正常空节点、旧告警恢复、执行错误、未应用配置、历史配置版本、待应用配置、普通线路、迁移配置和 Agent 离线。测试进程及临时构建目录已清理。三平台正式构建与安装检查以发布 Actions 为准。

## 升级与自测

正式 Release 发布后，在产生空节点告警的远端控制台机器执行：

```sh
curl -fsSL https://raw.githubusercontent.com/dovetaill/vless-chain/main/scripts/install-server.sh | sudo sh -s -- update --non-interactive
```

确认远端面板为 0.2.52，等待下一次监控检查及总控同步，空节点的“代理运行组件”告警应自动解除；无需创建无用代理或手动清除告警。仅升级主控不会替换远端面板的监控逻辑。

本版不改变 REALITY SNI、连接检测目标或代理配置；正式管理入口仍沿用现有 Python 实现。
