# 主题来源

基于用户提供的已购买主题 `metronic-tailwind-react-starter-kit_v9.5.0.zip` 中的 `typescript/vite/`。

选用 React + TypeScript + Vite，不需要 Next.js 运行时。保留主题的 Button、Card、Badge、Dialog、Input、工具函数和全局 Tailwind 设计变量；Dialog 关闭文案改为中文，全局样式将 Tailwind 扫描范围限定在源码。按线路管理需求编写页面与导航，精简主题配置，移除演示页面、图片、图表、地图、演示登录及无关依赖。登录和数据均接本项目 Rust API。

`src/components/ui/`、`src/lib/utils.ts`、`src/styles/globals.css`、`src/main.tsx` 来源于上述主题。主题版权及使用条件沿用购买时的许可；这些文件不因本项目使用而改变许可。四个原始 ZIP 未修改。
